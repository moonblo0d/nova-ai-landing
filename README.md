# NOVA — 3D-лендинг AI-асистента (three.js)

Промо-сторінка вигаданого продукту: AI-асистент, що відповідає клієнтам малого бізнесу в Telegram, Instagram і на сайті.

**Наживо:** https://moonblo0d.github.io/nova-ai-landing/

## Що всередині
- **3D-сцена на three.js:** «AI-ядро» — сфера з деформацією за 3D simplex noise у власному GLSL-шейдері,
  градієнт кольорів і ефект Френеля, кільце з частинок і зоряний фон;
- ядро **плавно переміщується між секціями під час скролу** і реагує на рух миші (паралакс камери);
- окремі позиції сцени для телефона, планшета й десктопа, щоб 3D не перекривало текст;
- економія ресурсів: менше полігонів і частинок на телефоні, пауза рендеру у фоновій вкладці,
  підтримка `prefers-reduced-motion`, запасний CSS-варіант без WebGL;
- **анімований демо-діалог** клієнта з асистентом у вигляді телефона (запускається при прокрутці до блоку);
- перемикач тарифів місяць / рік з анімацією цін, FAQ-акордеон, форма заявки з валідацією;
- адаптивна верстка, анімації появи блоків, жодного фреймворку.

## Стек
HTML · CSS · JavaScript (ES-модулі) · three.js · GLSL

